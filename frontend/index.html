Why this framework stands out

The OS Security Framework gives developers and security teams a polished interface for exploring information flow policies, verifying subject-object protection, and verifying access decisions with audit-friendly detail.

Confidentiality

Bell LaPadula model

Preserve data confidentiality by blocking unauthorized reads and writes using classical no read-up / no write-down enforcement.

Integrity

Biba model

Protect data integrity through integrity-level enforcement, ensuring subjects cannot compromise objects below or above their trust boundary.

Frequently asked questions

Answers to common questions about how the OS Security Framework works and how to extend it for your security exercises.

What is the Bell LaPadula model?
The Bell LaPadula model focuses on preserving confidentiality. It prevents subjects from reading data at a higher security level and from writing data to a lower security level.
What is the Biba model?
The Biba model is centered on integrity. It ensures subjects cannot write to objects with higher integrity or read from objects with lower integrity than their own.
How do subjects and objects map to OS entities?
Subjects typically represent users or processes, while objects represent files, resources, or data containers. The framework assigns security labels to both and evaluates access accordingly.
Can I extend the dashboard with custom models?
Yes. The React app is modular, allowing you to add additional models or policy rules. The landing page is built to support backend-driven decision logic and extra UI components.
Does the dashboard work on mobile?
The page is fully responsive, with adaptative layouts and touch-friendly navigation. The preview and content sections resize for smaller screens.
How do I connect to the backend?
Update the data service in your React app to point at the Python API endpoint. The UI can then fetch decisions, policy details, and alerts from the backend.
What is the root element for React?
The React application mounts into the element with id="root" inside the preview card. This keeps the landing page and dynamic app together.
Can this demo help with security training?
Absolutely. The interface is designed for teaching security concepts, demonstrating mandatory access control, and helping teams understand why requests are accepted or rejected.
